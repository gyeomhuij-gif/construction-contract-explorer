# 건설공사 계약관계 탐색기

## 사용 방법

1. `index.html`을 Chrome에서 엽니다.
2. 첫 화면의 업무 흐름도에서 계약 단계와 계약·협의·안전점검 관계를 한눈에 확인합니다.
3. 흐름도에는 건설폐기물 처리업체, 설치조건부 납품사, 건축물 미술작품 작가·설치사도 조건별 발주기관 계약으로 표시되어 있습니다.
4. 흐름도 카드를 누르면 아래 탐색기의 해당 주체 설명으로 이동합니다.
5. 토글 탐색기에서 계약 주체 이름을 선택하면 역할 설명, 실무 예시, 참고 출처가 표시됩니다.
6. 이름 왼쪽 화살표로 하위 계약 관계를 펼치거나 접고, 검색창에서 `관급`, `설계`, `안전점검` 등을 검색합니다.

별도 설치나 서버는 필요하지 않습니다. 제공된 Markdown 세 파일은 원본 참고자료로 같은 폴더에 두고, 법령 링크를 열 때는 인터넷 연결이 필요합니다.
